# Silas Ifeanyi Portfolio

Static GitHub Pages portfolio for Silas Ifeanyi.

## What is included

- `index.html` - revolving clickable graph homepage.
- `pages/iiot-conveyor.html` - IIoT and conveyor automation portfolio.
- `pages/sald-nano-manufacturing.html` - SALD, advanced manufacturing, nanotechnology, process control, and metrology portfolio.
- `pages/machine-learning-physical-ai.html` - machine learning, machine vision, edge AI, spectral/optical inspection, and Physical AI portfolio.
- `pages/healthcare-science-rnd.html` - healthcare innovation and science R&D portfolio.
- `pages/project-management-ideas-clinic.html` - IDEAs Clinic project management and technical leadership portfolio.
- `assets/` - extracted/consolidated images from provided portfolio and thesis materials.

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `silas-portfolio` or `isilas.github.io`.
2. Upload all files in this folder to the root of the repo.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Set branch to `main` and folder to `/root`.
6. Save and wait for GitHub Pages to publish the site.

## Claim boundary

Portfolio content is grounded in verified experience, published research and public project resources. Internal drafting notes are maintained separately and must not be published.

## Edit notes

- Add project images under `assets/<project>/`.
- Add or edit project pages under `pages/`.
- The graph nodes are in `index.html`; the animation behavior is in `script.js`.
